# Front-end

**MUHR Nexus** (Vite + React) lives in **`muhr-nexus/`**.

You can work either way:

- From this folder: `npm install` then `npm run dev` (scripts delegate to `muhr-nexus/`).
- Or: `cd muhr-nexus` and use `npm install` / `npm run dev` as usual.

Dev server: **http://127.0.0.1:8080** (proxies `/api` to the registry on :8000).
